# Yummy - Recipe Finder Web App

## Introduction

Welcome to **Yummy**, a web application designed to simplify recipe discovery and filtering. With **Yummy**, you can explore a wide variety of recipes based on your preferences, whether you're looking for meals by name, category, ingredients, or region. The app leverages the **Fetch API** to retrieve data from external sources, giving users a seamless experience while discovering new culinary creations.

Whether you're a novice cook or a seasoned chef, **Yummy** makes it easier than ever to find the perfect meal.

---

## Features

**Yummy** includes the following key features:

- **Search**: Find recipes by name or by the first letter of the dish.
- **Category Filter**: Browse recipes based on categories like **Pasta**, **Seafood**, **Desserts**, and more.
- **Area Filter**: Explore dishes from specific regions such as **Egyptian**, **Greek**, and other cuisines.
- **Ingredients Filter**: Refine your search based on ingredients like **Salmon**, **Beef**, **Chicken**, etc.
- **Contact Form**: A contact form that includes **Regex validation** for proper input. The submit button is dynamically enabled when all fields are correctly filled out.
- **Smooth User Experience**: The app includes **loading animations** and **transitions** to enhance the user experience during data fetching.

---

## Technologies Used

**Yummy** is built using the following technologies:

- **HTML5**: For structuring the web pages.
- **CSS3**: For styling and layout design.
- **Bootstrap 5**: For a responsive, mobile-first design.
- **JavaScript (ES6+)**: For interactive features and DOM manipulation.
- **jQuery**: For easier DOM traversal and event handling.
- **Fetch API**: To dynamically retrieve and display data from an external source.

## Installation

To run **Yummy** locally, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/yummy.git
    ```

2. **Navigate to the project folder**:
    ```bash
    cd yummy
    ```

3. **Open `index.html`** in your preferred browser to start using the app.

---

## Usage

After following the installation steps:

- **Search for Recipes**: Use the search bar to look up specific recipes by name.
- **Apply Filters**: Filter recipes based on category, region, or ingredient.
- **View Recipe Details**: Click on any recipe to view more information and get the recipe's instructions.
- **Contact Form**: Reach out with any questions or feedback using the contact form.
